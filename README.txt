EXAM ALLOCATOR - PYTHON CODE

1. Open this folder in Visual Studio Code.
2. Open a terminal: Terminal > New Terminal.
3. Run: python3 exam_allocator.py
4. Choose option 6 for the full demonstration.

The program uses only Python's standard library. It creates seating_plan.csv, faculty_duties.csv and exam_allocator_dashboard.html in the current working folder.
The bundled student, room and faculty details are fictional sample data.
